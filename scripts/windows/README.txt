AI ADS Studio for Windows
=========================

Run the installer and follow the setup steps. The installer includes the
application, its Vietnamese voice models, Python runtime, and video tools.

Usage
-----
The app opens directly without a sign-in screen and runs only on this computer
at http://127.0.0.1:8080. A desktop shortcut starts the local service and opens
the application in your browser.
Use the Start Menu shortcut to start it again. Close the minimized server
window to stop the local service.

Generated videos remain on this computer after uninstalling the application.
Back them up before removing them manually.

Troubleshooting
---------------
- If the application does not open, try launching it again from the Start Menu.

Important
---------
The installer contains the publisher's Groq API key so local installations can
generate scripts without additional configuration. Anyone who receives the
installer can extract and use that key. The publisher is responsible for any
usage and charges from the shared key.
